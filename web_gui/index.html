03 / METHODOLOGY
A model is a hypothesis.
Test the assumptions.
Synthetic opponents illustrate behavior; they do not represent the actual applicant field. A strong result under one model is not a universal winning strategy.
001 Head-to-head evaluates every opponent. Four-way samples three distinct applicants per group and splits tied ranking payouts.
002 Search uses a separate training population and seed. Game 1 uses an exact dynamic program; Game 2 uses a finite randomized search.
003 Four-way intervals describe Monte Carlo sampling uncertainty, not uncertainty about the opponent model. Browser seeds use a different generator from Python.
OPPONENT MODELS + CSV FORMAT
Balanced mixes equal and proportional allocations with small perturbations. Diverse mixes broad, value-weighted and concentrated random allocations. Concentrated favors two or three fields.
Import five integer columns totaling 100 per row, optionally preceded by an applicant name. An optional header is accepted. At least three applicants are required. Imported rows form the fixed population for both training and independent test groups.
